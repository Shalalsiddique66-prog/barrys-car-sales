# Barry's Car Sales: accessibility and usability improvements

Improved version of the supplied Barry's Car Sales starter site, evaluated against WCAG 2.2 level AA and Nielsen's usability heuristics.

## Structure
- `index.html`, `about.html`, `enquiry.html`, `privacy.html`: the improved pages
- `styles.css`, `script.js`, `favicon.svg`: shared styling and form validation
- `*.jpg`: car photographs (stock-agency previews; replace with licensed images before public use)
- `original/`: the supplied starter site, unchanged, for comparison
- `evaluation/`: evidence from the before and after testing

## Run it
Open `index.html` in a browser. No server or build step is needed.

## Evaluation tools
Lighthouse, axe-core and WAVE for automated checks, plus manual keyboard, reflow and VoiceOver (macOS) checks. See `evaluation/`.
